# Contributing

VocalCode's application source is not published in this repository. This public
repository is for documentation, support and reproducible bug reports.

## Report a bug

Use the bug-report form and include the operating system, VocalCode version,
expected behavior and what happened. The log locations and privacy cautions are in
[Troubleshooting](docs/troubleshooting.md).

Do not post licence keys, purchase receipts, email addresses, local usernames or
unreviewed logs in a public issue. Send purchase and licence questions to
**support@vocalcode.app**.

## Suggest a feature or documentation correction

Open a feature request for product ideas. Documentation corrections can be filed
as an issue or proposed as a pull request. Keep product comparisons factual and
link to primary sources for claims about another product.
