# Security policy

## Reporting a vulnerability

Please do not open a public issue for a suspected security or privacy problem.
Email **support@vocalcode.app** with:

- the affected VocalCode version and operating system;
- clear reproduction steps;
- the security or privacy impact you observed; and
- any logs or screenshots after removing unrelated personal information.

Reports are reviewed privately. Please allow time to reproduce and fix an issue
before publishing technical details that could put other users at risk.

## Supported versions

Security fixes are provided through the current production release. Check
<https://vocalcode.app/latest.json> for the current version and use the updater or
the official downloads at <https://vocalcode.app/>.
