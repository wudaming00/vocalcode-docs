## Short description

Push-to-talk voice input for AI coding, with on-device speech recognition for
Windows and Apple silicon Mac.

## Description

VocalCode turns speech into text wherever you write AI coding prompts,
documentation, messages, and other prose. Hold a configured key or mouse button,
speak, and release; the recognized text is inserted into the active field in
most desktop apps.

After the selected model downloads, speech recognition runs on your machine.
VocalCode does not upload recognition audio or transcripts. Internet access is
still required for initial trial provisioning, model and update downloads,
checkout, activation, and periodic paid-licence validation.

The app includes a 30-day trial with every feature enabled. A licence costs
$4.99 once, plus applicable tax, with no subscription.

## Features

- Hold, speak, and release push-to-talk workflow
- On-device speech recognition after model download
- Works in most desktop text fields
- Configurable keyboard and mouse shortcuts
- Personal Dictionary corrections
- Windows 10/11 x64 support
- 30-day full trial and one-time purchase
