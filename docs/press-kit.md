## One-line description

VocalCode is local push-to-talk dictation for AI coding on Windows and Apple
silicon macOS.

## Short description

Hold a configured key or mouse button, speak, and release. VocalCode recognizes
speech on the user's machine after the selected model downloads, cleans the text,
and inserts it into the active field in most desktop apps. It is designed for
dictating prompts, documentation and other prose while coding.
